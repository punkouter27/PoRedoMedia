An empty Library used to be one sentence. Now it explains what goes there and is itself the drop zone (drop, paste, choose a file or use the camera, with no Add media click first). While the Library loads, placeholder cards the shape of real ones show, so nothing jumps when the items arrive.

23 · 44Create in three steps

Pick media → Functions → Run, shown as tabs beside the title. A step that is done can be clicked to go back; one not reached yet cannot. Each step fits a laptop screen: the preview is shorter, recipes and "save as recipe" share one row, and the run step puts its buttons and the runs left today on one line. Create.razor went from 455 to 394 lines with CreateSteps, RecipeBar and RunView split out, and Gallery.razor from 430 to 369, its markup now in LibraryToolbar, LibraryGrid and MediaDrawer.

The "What looks at the picture: Server / On device" picker is gone. With Settings → On-device AI on, Settings offers Get the model ready (about 230 MB, once). From then on Create describes the picture on the device by itself and falls back to the server if that fails (a short notice says so). The summary line says which will look, the estimate counts it, and the run shows a small Picture described: On device / Server chip (only once On-device AI is on, so the default app stays plain).

Each run is a card: icon, what it did and how it went, then its buttons, which drop under the words on a phone.
